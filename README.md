
# Hospital-Patient-Appointment-Management-System


## 📌 Task

Develop a **console-based Hospital Patient & Appointment Management System** using **Python OOP**.

## 🏥 Classes

Create the following classes:

* `Patient`
* `Doctor`
* `Appointment`

## 🔹 Requirements

### Patient

* Add patient
* View patient details
* Update patient details

### Doctor

* Add doctor
* View doctor details
* Display specialization

### Appointment

* Book appointment
* View appointment
* Cancel appointment
* Update appointment status

## 🧠 Concepts to Use

* Classes & Objects
* Constructor
* Encapsulation
* Inheritance
* Polymorphism
* Lists / Dictionaries
* Functions
* Exception Handling
